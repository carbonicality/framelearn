# framelearn (better name: framebuild)
framelearn/framebuild is a fun website where you can build your own 'framework'.

it's not accurate, and it's not for real frameworks, but you could argue it's like a PCPartPicker for laptops

i created this project for week 8/12 (the one with the 'framework' theme) of siege, a Hack Club YSWS.

features:
- display size picker
- ram picker
- storage picker
- I/O picker
- cpu picker
- overviews
- import/export/view summary/copy config to clipboard system
- preset system
- graph system for power draws
- performance benchmarks
- battery life estimator
